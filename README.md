# Sandeep Yadav Portfolio

Static, responsive portfolio website for GitHub Pages.

## Folder structure

portfolio/
├── index.html
├── style.css
├── script.js
├── assets/
│   ├── images/
│   │   └── profile.jpg
│   └── resume/
│       └── Sandeep-Yadav-Resume.pdf
├── certificates/
│   ├── python-certificate.pdf
│   ├── web-development-certificate.pdf
│   └── certificate3.pdf
└── projects/

## Before publishing

Replace every `[REPLACE ...]` / `[YOUR ...]` placeholder in index.html and the email in script.js.

Add:
- Your profile photo as assets/images/profile.jpg
- Your resume as assets/resume/Sandeep-Yadav-Resume.pdf
- Your genuine certificate PDFs inside certificates/
- Your actual GitHub and LinkedIn URLs
- Your real project repository links
- Live demo links only for projects that are actually hosted

## Run locally

Open index.html in a browser, or use VS Code Live Server.

## GitHub Pages

1. Create a public GitHub repository.
2. Upload the contents of this folder.
3. Go to Settings -> Pages.
4. Under Build and deployment choose "Deploy from a branch".
5. Select branch `main` and folder `/ (root)`.
6. Save and wait for deployment.
7. Your project site will normally be:
   https://YOUR-USERNAME.github.io/REPOSITORY-NAME/

This is a static site and does not require XAMPP, PHP or MySQL.
